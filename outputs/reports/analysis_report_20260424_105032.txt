  3. IMAGE QUALITY ANALYSIS
======================================================================

  For each face (detected / undetected / false positive), we measure:
    - Face area: bounding box width × height (pixels²)
        Example: 256 px² ≈ 16×16 pixel face (very tiny)
                 1,024 px² ≈ 32×32 pixel face (small)
                 4,096 px² ≈ 64×64 pixel face (medium)
    - Face brightness: mean value of HSV V-channel (0=black, 255=white)
        < 80 → dark face (hard to detect)
        80–180 → normal illumination
        > 180 → bright / overexposed
    - Image blur: variance of Laplacian operator on grayscale image
        < 50 → blurry image
        50–200 → moderate sharpness
        > 200 → sharp image
    - Confidence: model's certainty for its detection (0.0–1.0)
